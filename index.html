Introduction

What Python is and how to run it.

Python is a high-level, interpreted, dynamically typed language known for readable syntax. It is used for automation, web back ends, data analysis, machine learning and scripting.

  • Indentation (4 spaces) defines blocks; there are no braces.
  • Everything is an object, including functions and classes.
  • Run a file with python app.py or experiment in the REPL with python.
# hello.py
print("Hello, World!")
name = input("Your name: ")
print(f"Welcome, {name}")

Functions

Reusable blocks with flexible arguments.

def greet(name, greeting="Hello", *args, **kwargs):
    """Return a greeting string."""
    return f"{greeting}, {name}!"

greet("Ravi")
greet(name="Meena", greeting="Hi")

square = lambda x: x * x
list(map(square, [1, 2, 3]))
list(filter(lambda x: x % 2, [1, 2, 3]))

def counter():
    count = 0
    def inc():
        nonlocal count
        count += 1
        return count
    return inc           # closure
Warning: never use a mutable default such as def f(x=[]). Use None and create the list inside.

def fib(limit):
    a, b = 0, 1
    while a < limit:
        yield a
        a, b = b, a + b

Object-Oriented Programming

Classes, inheritance and special methods.

class Account:
    bank = "Northwind"                 # class attribute

    def __init__(self, owner, balance=0):
        self.owner = owner
        self._balance = balance

    @property
    def balance(self):
        return self._balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Amount must be positive")
        self._balance += amount

    @classmethod
    def empty(cls, owner):
        return cls(owner)

    def __str__(self):
        return f"{self.owner}: {self._balance}"

class Savings(Account):
    def __init__(self, owner, balance=0, rate=0.04):
        super().__init__(owner, balance)
        self.rate = rate

acc = Savings("Asha", 1000)
acc.deposit(500)
print(acc)

Exceptions

Handle failure without crashing.

try:
    value = int(input("Number: "))
    result = 10 / value
except ValueError:
    print("Not a number")
except ZeroDivisionError as e:
    print("Error:", e)
else:
    print("Result", result)
finally:
    print("Always runs")

class InsufficientFunds(Exception):

Decorators & Standard Library

Tools that make code concise and professional.

import time
from functools import wraps

def timer(fn):
    @wraps(fn)
    def wrapper(*a, **kw):
        start = time.perf_counter()
        out = fn(*a, **kw)
        print(f"{fn.__name__}: {time.perf_counter()-start:.4f}s")
        return out
    return wrapper

@timer
def work():
    return sum(range(10**6))

Best Practices

Habits that keep code maintainable.

  • Follow PEP 8: snake_case for functions and variables, PascalCase for classes.
  • Write docstrings and add type hints: def add(a: int, b: int) -> int.
  • Prefer with blocks for files and connections.
  • Catch specific exceptions; never use a bare except:.
  • Use virtual environments and pin dependencies in requirements.txt.
  • Write tests with pytest and format with black or ruff.
